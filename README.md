# Устройство мониторинга качества воздуха на базе ESP32 (Wokwi)

Данный проект полностью соответствует вашей пояснительной записке к производственной практике.

## Структура файлов проекта
* `diagram.json` — принципиальная схема компонентов и проводных соединений для симулятора Wokwi.
* `sketch.ino` / `src/main.cpp` — исходный код прошивки на C++ (опрос датчиков, светозвуковая индикация, авто-вентиляция, встроенный HTTP веб-сервер и интерфейс).
* `libraries.txt` — список библиотек для симулятора Wokwi (`ArduinoJson@^7.0.0`).
* `platformio.ini` — файл сборки для PlatformIO.
* `wokwi.toml` — файл конфигурации симулятора Wokwi и проброса портов (`80 -> 8180`).

## Вариант 1. Запуск прямо в браузере на сайте Wokwi (самый простой)

1. Откройте в браузере сайт: **[https://wokwi.com/projects/new/esp32](https://wokwi.com/projects/new/esp32)**
2. Перейдите на вкладку **`diagram.json`** в редакторе Wokwi и полностью замените её содержимое текстом из файла `diagram.json`. На экране сразу появится вся схема: ESP32, 2 датчика газа MQ, 4 светодиода, резисторы, зуммер и модуль реле!
3. Перейдите на вкладку **`sketch.ino`** и замените код содержимым из файла `sketch.ino`.
4. В панели файлов слева нажмите на вкладку **`Library Manager`** (или добавьте файл `libraries.txt`) и добавьте библиотеку:
   ```
   ArduinoJson
   ```
5. Нажмите зелёную кнопку **«Start Simulation» (Play)**.
6. **Как проверять работу устройства:**
   * Кликайте мышкой по датчикам **MQ-2** и **MQ-135** — у них появятся ползунки концентрации газа.
   * **< 400** — горит зелёный светодиод (чистый воздух), зуммер и реле выключены.
   * **400–700** — загорается жёлтый светодиод (лёгкое загрязнение).
   * **701–900** — загорается оранжевый светодиод, реле вентилятора автоматически включается!
   * **> 900** — загорается красный светодиод, включается реле вентилятора и звучит тревожный зуммер (1000 Гц).
   * В окне терминала (Serial Monitor) каждые 2 секунды выводятся текущие показания датчиков и статус системы.

## Вариант 2. Запуск локально в VS Code с расширением Wokwi

1. Откройте папку `Wokwi_ESP32_AirMonitor` в редакторе **Visual Studio Code**.
2. Установите расширения **PlatformIO IDE** и **Wokwi Simulator**.
3. Скомпилируйте проект через PlatformIO (кнопка `Build` внизу с галочкой).
4. Нажмите клавишу **F1** (или `Ctrl + Shift + P`) и выберите:
   ```
   Wokwi: Start Simulator
   ```
5. Контроллер подключится к виртуальной сети Wi-Fi, а порт `80` пробросится на ваш компьютер:
   Откройте в любом браузере: **`http://localhost:8180`**
   * Вы увидите полноценный веб-сайт мониторинга качества воздуха с карточками датчиков MQ-2, MQ-135, индикатором состояния и кнопками ручного/автоматического управления вентилятором!
